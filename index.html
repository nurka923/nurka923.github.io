Builtn8n · ActiveCampaign · Claude

AI Outreach Pipeline: Personal Email for Every Lead

A fully automated outreach pipeline that removes manual email writing for every incoming lead. Claude writes a personalised subject line and a 3-sentence email from the lead's name, company and status. The email goes out through Gmail, the CRM is updated and a Telegram summary arrives in real time.

0 manual emails · <5 s from lead to inbox · 100% CRM tracking (in test runs)
Webhook→AC lookup→Claude AI→Gmail→AC custom fields→Segment & tag→Telegram
How it works
  • A webhook receives the lead data (email, first name, company)
  • An ActiveCampaign API lookup finds the contact and reads its tags
  • A contact that was already emailed is skipped, so nobody gets a duplicate
  • Claude returns strict JSON with subject and body, parsed in a Code node
  • The email content is saved to custom fields on the ActiveCampaign contact
  • Warm leads are segmented and tagged in the pipeline
  • The video above is a real run that ends with "Workflow executed successfully"

Builtn8n · Bot API · Speech-to-Text

AI Assistant Bot with Voice Recognition & Multi-LLM Routing

A production-ready AI assistant on n8n. Text messages go straight to a Basic LLM Chain. Voice messages are downloaded, transcribed with Speech-to-Text, then processed by AI before the reply is sent. Unauthorised users are blocked at the access-check stage, and the bot can publish content to channels automatically.

Trigger→Access check→Switch→Voice → Text→LLM Chain→Answer
How it works
  • Access control by chat.id; everyone else gets a "prohibited" message
  • A Switch node routes /start, /clear and free text
  • Voice branch: download file → Speech to Text (Whisper) → AI
  • Multi-LLM: OpenRouter and OpenAI chat models, with fallback when one hits a rate limit
  • A "typing…" indicator while the AI works, and memory per user
  • A separate error workflow sends a Telegram alert with the failed node

AI Content Pipeline for Telegram
